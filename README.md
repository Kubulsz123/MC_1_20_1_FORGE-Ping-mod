# Zombie Apocalypse Ping Mod
A custom client-server ping system for Minecraft 1.20.1 (Forge).

## Features
* **Custom Ping Graphic:** Renders a 2D billboarded PNG in the 3D world.
* **Extended Raycasting:** Pings exactly where you look, up to your maximum chunk render distance (ignoring standard player reach limits).
* **Constant Visual Scaling:** The ping marker remains the same visual size on your screen regardless of how far away it is.
* **Distance Indicator:** Displays the exact distance in blocks above the ping marker.

## How to Use
Press the configured keybind (default `P`) while looking at any loaded block.

## Development
Built for Minecraft 1.20.1 using Minecraft Forge.
